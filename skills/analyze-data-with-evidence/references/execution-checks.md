# 执行检查

按当前任务读取相关小节。用检查解决具体风险，不要求每个小任务完成全部项目。

## 数据读入、获取与清洗

- 先核对来源、文件内容、时间覆盖、一行粒度、主键、字段类型、单位、时区和空值约定。保留原始文件；把清洗写成可复现步骤。
- CSV 用解析器处理分隔符、引号内逗号与换行；编号按文本保留前导零。JSON 用标准解析器，逐层确认对象和数组；不要执行外部文本。
- 编码错误先保留原始字节并查来源，再有限尝试；不要用忽略解码错误或“终于不报错”作为正确标准。
- 区分缺失、零、未知、不适用和未到观察期。说明删除、插补或保留的理由及影响；极端值先核实，不能为了显著或提高分数直接删除。
- 展开列表前声明粒度如何改变。连接前检查预期的一对一、一对多或多对多关系；连接后复核行数、唯一键、未匹配量与关键总额，防止订单金额随明细重复累计。
- 导出后回读，复核列名、行数、编号、类型、关键数值和缺失语义；按文件特性检查精度和日期。
- 需要网页/API 数据时，先查可用的稳定来源及实际授权范围。逐次检查状态、内容类型、业务结构和记录字段，按同一记录容器提取字段。尊重配额并限定重试；凭证不得写入交付代码或日志。
- 分页按文档推进并检测重复游标；记录结束原因、失败页、唯一记录数和覆盖区间。达到上限或采集停止不等于取全。保存时区分解析数、有效数、尝试写入数、实际新增数。

## 指标与结构比较

- 给核心指标写出分子、分母、单位、观察窗口、去重单位及纳入排除规则。比较两期时确认口径未变，且均有完整观察窗口。
- 合并比例使用总分子/总分母，或等价的分母加权平均，不直接平均各组比例。未知分类保留并计入覆盖核对。
- 同时报告绝对量与比率。百分比到百分比的直接差称百分点；相对变化以明确基期为分母。基期为零时不报普通增长率。
- 检查组内变化和权重变化；若共同权重有意义，声明目标总体和标准化权重。结构分解解释算术变化，不能单独识别干预效果。
- 使用指标恒等式前检查口径。例：GMV = 访客数 × 购买用户转化率 × 人均订单数 × 每单金额，需在同一期间、同一总体且订单口径一致时成立。不能在允许多单的业务中省略频次。
- 多因子的相对变化不能直接相加作为精确总变化。做贡献分解时说明基期、顺序或分摊方法及交互项处理；不要把会计贡献写成原因。

## 统计与建模

| 任务 | 最小有效分析 | 需要额外说明 |
| --- | --- | --- |
| 描述现状 | 样本量、分布、趋势、适配的中心与离散程度 | 样本覆盖、缺失和口径，是否需要外推 |
| 群体差异 | 差异大小及区间，合适时做检验 | 独立/配对/重复测量，聚类、样本设计、假设与多重比较 |
| 诊断变化 | 分层、同期群、漏斗、指标分解与候选机制核对 | 构成变化、埋点/口径变更、替代解释 |
| 预测 | 简单基线、符合实际使用场景的验证、适配损失 | 预测起点与窗口、可用特征、误差分布、校准或预测区间 |
| 干预效果 | 明确干预、对照、目标总体、结果和研究设计 | 混淆、选择、时间顺序、干扰与外推，具体识别假设 |
| 行动优化 | 目标函数、预算等约束、候选方案与基线 | 成本、敏感性、模型外约束和试点验证 |

- 按分析单位而不是表格行数判断独立性。同一人多次记录、同一门店多日记录可能需要配对、聚类或时序处理。
- 不默认所有问题都需要显著性检验。需要推断时报告效应量、区间、样本量与实际意义；p 值不表示原假设为真的概率，不显著也不自动证明没有影响。
- 区分事先计划与探索发现；记录筛选、窗口和模型尝试。按问题处理多重比较，或使用独立数据确认。不要通过反复查看留出集继续调参，再称其为独立验证。
- 预测按部署场景划分时间或群体，先划分再在训练数据/每个训练折内拟合插补、标准化、特征选择和调参。禁止使用预测时尚不可知的结果字段或未来数据。
- 时间序列按预测起点构造滞后与滚动特征，使用可获得的数据回测；检查季节性、时间依赖和结构变化。训练集误差不足以证明泛化。
- 方法升级要比较同一验证口径下相对基线的增益、稳定性、可解释性和成本。没有可验证增益时保留简单方案。
- 因果判断需要设计和假设，回归系数、特征重要性、相关显著或预测准确均不能自动解释为干预效果。没有识别依据时给候选机制和验证方案。
- 能估计时给合适的不确定性；不能估计时说明原因及影响结论的主要不确定性。场景范围若非统计区间，应明确叫情景分析。

## 图表与沟通

- 为每张交付图写一个要回答的问题；删除重复或与主问题无关的图。探索阶段允许保留待验证图，交付时说明其探索性质。
- 趋势用折线，分类比较用条形，分布用直方/箱线等，变量关系用散点；根据数据和问题选择，不凑齐图表类型。
- 标明指标、单位、时间范围、样本量或分母、必要来源及不确定性。对比保持可比尺度和分类顺序。
- 柱形长度通常用零基线。折线缩窄范围时清楚标尺。避开装饰性 3D；双轴不支持相关或因果判断，可改小多图或同基期指数，并保留原始水平。
- 气泡用面积而非半径对应数量。颜色分级需明确业务阈值、图例和文字，不凭红绿制造好坏判断。
- 检查小基数、截取时间窗、累计与当期量、过度小数精度。不要因视觉差距小就断言业务不重要。
- 面向决策者先给有条件的结论；技术细节放后面。事实和限制对所有受众保持一致。标题不能比证据更强，不强制每张探索图使用结论标题。

## 交付前按六原则检查

| 原则 | 完成条件 |
| --- | --- |
| 问题导向 | 每个主要结果回到明确问题与比较对象 |
| 数据诚实 | 数字可追溯，未知和模拟明确，关键反例与局限保留 |
| 可复现 | 数据版本、代码、参数、必要随机种子、环境与运行步骤足够复算 |
| 受众适配 | 先回答读者关心的问题，术语、图表和精度合适 |
| 从简单开始 | 已有合理基线，增加复杂度有证据和用途 |
| 可行动 | 明确下一步、触发条件及评估方式，证据不足时以补数或验证为行动 |

最后抽样回查核心数字，复算分子分母，确认摘要、正文、表和图一致。只完成实际需要的核对，不把一般建议写成已执行检查。
